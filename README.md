# Monthly Sales & Performance Dashboard

An interactive sales analytics dashboard built using Microsoft Excel to analyze sales performance, revenue, profit, orders, customers, regions, categories, payment modes, and top-selling products.

## 📊 Project Overview

This project transforms raw sales data into an interactive Excel dashboard that helps understand business performance and identify important sales trends.

The dashboard provides a clear view of monthly sales performance and allows users to filter the analysis using interactive slicers.
